Phase 2C performed threshold sensitivity analysis for the Phase 2A selected hybrid ensemble. The original threshold was selected on the validation set and remained fixed for final held-out test evaluation. Threshold sweeping on the held-out test predictions was used only as a sensitivity analysis, not for reselecting the final operating point. Around the validation-selected threshold of 0.0275, the model maintained high recall while showing the expected trade-off between PPV and specificity. At the nearest tested threshold of 0.028, the model achieved PPV 0.3289, recall 0.9615, specificity 0.8846, with 51 false positives and 1 false negatives. The sweep also showed that higher thresholds could further reduce false positives while keeping false negatives at 1; for example, the top safe threshold in the sensitivity sweep was 0.039, with PPV 0.4167, recall 0.9615, specificity 0.9208, 35 false positives, and 1 false negatives. However, this higher threshold was not adopted as the final model threshold because it was identified using held-out test analysis. Therefore, Phase 2C supports that the validation-selected hybrid threshold is clinically conservative and stable, while also showing that the model has a useful operating range for future validation.
