Phase 2D finalized and locked the best-performing model configuration for thesis reporting. The final selected model is the Phase 2A Selected Hybrid Ensemble, consisting of the Phase 1 baseline ResNet-18 with weight 0.90, the Phase 1 weighted-augmentation ResNet-18 with weight 0.05, and the Phase 2A MaxViT-Tiny 384 model with weight 0.05. The final operating threshold is 0.027517, which was selected using validation data only; the held-out test set was not used for threshold selection. On the held-out test set, the final hybrid achieved recall 0.9615, PPV 0.3205, specificity 0.8801, AUROC 0.9888, and AUPRC 0.9154, with 53 false positives and 1 false negative. Compared with the Phase 1 ResNet ensemble, the hybrid reduced false positives from 86 to 53 while maintaining the same recall and false-negative count. Bootstrap analysis confirmed that this improvement was stable, with a mean false-positive reduction of 32.57 cases and a 95% confidence interval of [21.00, 45.00]. Per-centre bootstrap analysis also showed consistent false-positive reduction in both center_1 and center_2. Therefore, the Phase 2A Selected Hybrid Ensemble is locked as the final thesis model for high-sensitivity neoplasia screening.
